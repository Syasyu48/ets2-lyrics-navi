# ETS2 Lyrics NAVI

ETS2 Lyrics NAVI は、Euro Truck Simulator 2,TruckersMP向けの非公式プラグインです。[TruckersMP Game Client SDK](https://github.com/TruckersMP/GameClientSDK) を使い、車内のナビ画面に歌詞を重ねて表示します。Spotifyで再生中の曲と再生位置に合わせ同期歌詞を取得し表示します。

### 歌詞データの取り扱い

利用規約に則り、歌詞はアプリ内での表示に使い、APIレスポンスの再配布は行いません。
